## ❓ Perguntas Frequentes
<details>
<summary><b>💰 É pago?</b></summary>
Não, o código é 100% gratuito e open-source.
</details>
<details>
<summary><b>📱 Funciona em qualquer celular?</b></summary>
Sim, basta ter o Termux instalado para rodar o bot no Android.
</details>
<details>
<summary><b>👑 Como virar dono do bot?</b></summary>
Configure seu número no arquivo de configuração do projeto.
</details>
<details>
<summary><b>🛞 Instalação no termux</b></summary>
Abra o termux e faça em sequência o que está ai

1️⃣ pkg update && pkg upgrade
  
2️⃣ pkg install git nodejs -y

3️⃣ git clone [https://github.com/neozeraa/gretbot](https://github.com/neozeraa/gretbot)

4️⃣ cd gretbot

5️⃣ npm install

6️⃣ npm start

</details>
