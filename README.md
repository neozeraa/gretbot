## ❓ Perguntas Frequentes
<details>
<summary><b>💰 O bot é 100% gratuito?</b></summary>
Sim, totalmente gratuito! O código é aberto (*open-source*), sem taxas ou cobranças ocultas, para você usar e modificar à vontade.
</details>
<details>
<summary><b>📱 Funciona em qualquer celular?</b></summary>
Sim, desde que seja um aparelho Android com o aplicativo Termux instalado, permitindo executar todas as funções do bot diretamente no seu dispositivo.
</details>
<details>
<summary><b>👑 Como faço para definir o meu número como dono (admin) do bot?</b></summary>
Siga o passo a passo abaixo para configurar o seu número:
  
1️⃣ Abra o gerenciador de arquivos ou use o próprio Termux para entrar na pasta do bot: `cd gretbot`

2️⃣ Localize e abra o arquivo de configuração principal (geralmente chamado de `config.js`, `settings.js` ou localizado na pasta `lib`/`src`).

3️⃣ Procure pelo campo reservado para o número do proprietário, dono ou admin.

4️⃣ Insira o seu número de telefone completo, incluindo o código do país (ex: `55`) e o seu DDD, apenas com números (ex: `5511999999999`).

5️⃣ Salve as alterações no arquivo.

6️⃣ Reinicie o bot no Termux (`npm start`) para aplicar as permissões de dono.
</details>
<details>
<summary><b>🛞 Instalação no termux</b></summary>
Abra o termux e faça em sequência o que está ai
1️⃣ `pkg update && pkg upgrade`
  
2️⃣ `pkg install git nodejs -y`

3️⃣ `git clone https://github.com/neozeraa/gretbot`

4️⃣ `cd gretbot`

5️⃣ `npm install`

6️⃣ `npm start`

7️⃣ `Aguarde o carregamento inicial e a leitura do QR Code do WhatsApp na tela.`

8️⃣ `Utilize outro aparelho para ler o QR Code gerado e conectar sua sessão.`

9️⃣ `Mantenha o aplicativo Termux rodando em segundo plano sem fechar a aba.`

🔟 `Teste os comandos do seu bot diretamente no número conectado!`
</details>
